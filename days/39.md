## Solution
1. Login to the Azure portal using the provided credentials.
2. Create a new storage account named `xfusionwebst50708663` in the **East US** region with **Locally-redundant storage (LRS)**.
3. Navigate to the storage account's "Static website" settings and enable static website hosting while setting `index.html` as the index document.
4. Navigate to teh 'Configuration Settings' and "Allow blob public access" to enable public access to the static website.
5. Navigate to the `$web` container in the storage account and change the access level to "Blob (anonymous read access for blobs only)".
6. Run the following command on the `azure-client` to upload the `index.html` file to the `$web` container:
```bash
az storage blob upload --account-name xfusionwebst50708663 --container-name '$web' --name index.html --file /root/index.html
```
7. Navigate to the "Static website" settings in the storage account to find the primary endpoint URL for the static website. Open this URL in a web browser to verify that the static website is accessible and displays the content of `index.html`.
