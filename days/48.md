## Solution
1. Log in to the Azure portal using the provided credentials.
2. Naviagate to the Virtual Machines section and create a new VM with the following specifications:
   - Name: `xfusion-vm`
   - Region: East US
   - Availability options: No infrastructure redundancy required
   - Image: Ubuntu Server 20.04 LTS
   - Size: Standard B1s (1 vcpu, 1 GiB memory)
   - Authentication type: SSH public key (use existing public key created on azure-client host)
   - Select Inbound ports: Allow selected ports (SSH, HTTP)
   - OS Disk Type: Standard SSD
3. Create an Azure Container Registry (ACR) named `xfusionacr581643416` in the `East US` region.
4. Create a storage account named `xfusionstor581643416` in the `East US` region with `Locally-redundant storage (LRS)`.
5. Create a Blob container named `xfusion-config` in the storage account.
6. Run the following commands on the `azure-client` host to build and push the Docker image to ACR:
    ```bash
    cd pyapp/
    az acr login --name xfusionacr581643416
    docker build -t xfusionacr581643416.azurecr.io/xfusion/python-app:latest .
    docker push xfusionacr581643416.azurecr.io/xfusion/python-app:latest
    ```
7. SSH into the VM and install Docker and Azure CLI using the following commands:
    ```bash
    ssh azureuser@<xfusion-vm-public-ip>
    sudo apt update
    sudo apt install -y docker.io
    sudo systemctl enable docker
    sudo systemctl start docker
    sudo usermod -aG docker azureuser
    sudo groupadd docker
    curl -fsSL 'https://azurecliprod.blob.core.windows.net/$root/deb_install.sh' | sudo bash
    exit
    ```
8. Copy the `config.json` file to the VM using SCP:
    ```bash
    scp config.json azureuser@<xfusion-vm-public-ip>:/home/azureuser/
    ```
9. SSH into the VM, log in to the ACR using the credentials found in the access keys section under the ACR settings, and run the Docker container:
    ```bash
    ssh azureuser@<xfusion-vm-public-ip>
    docker login xfusionacr581643416.azurecr.io 
    docker run -d -p 80:80 -v /home/azureuser/config.json:/app/config.json --name xfusion-app xfusionacr581643416.azurecr.io/xfusion/python-app:latest
    ```
10. Upload the `config.json` file to the Blob container using the Azure CLI:
    ```bash
    az storage blob upload --account-name xfusionstor581643416 --container-name xfusion-config --name config.json --file config.json
    ```
11. Verify that under the Blob container, the `config.json` file is present.
