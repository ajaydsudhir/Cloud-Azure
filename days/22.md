## Solution
1. Login to the Azure portal using the provided credentials.
2. Navigate to the "Virtual Machines" section and click on "Create" to start the VM creation process.
3. Fill in the required details:
    - **Instance Name:** `nautilus-vm`
    - **Region:** `East US`
    - **Image:** Select an available Ubuntu image (e.g., Ubuntu 24.04 LTS).
    - **Size:** Choose an appropriate size for the VM (e.g., Standard B1s).
    - SSH Key: You can generate an SSH key pair through the azure client and use it for authentication.
4. In the "Advanced" tab, locate the "Custom Data" or "User Data" field and add the custom script:
```bash
#!/bin/bash
sudo apt update
sudo apt install -y nginx
sudo systemctl start nginx
sudo systemctl enable nginx
```
5. Configure the Network Security Group (NSG) to allow HTTP traffic on port `80` from the internet.
6. Review the configuration and click "Create" to deploy the VM.
