# Day 3: Create VM using Azure CLI

## Task
The Nautilus DevOps team is in the process of migrating some of their workloads to Azure. One of the tasks involves creating a new Virtual Machine (VM) using the Azure CLI. The team does not have access to the Azure portal but can manage Azure resources via the `azure-client` host (the landing host for this lab).
1) Create a new Azure Virtual Machine named `devops-vm` using the Azure CLI.
2) Use the `Ubuntu2204` image and set the VM size to `Standard_B2s`.
3) Make sure the admin username is set to `azureuser` and SSH keys are generated for secure access.
4) Use `Standard_LRS` storage account, disk size must be `30GB` and ensure the VM `devops-vm` is in the `running` state after creation.

## Solution
1. Determine the name of the resource group where the VM will be created using the following command:
    ```bash
    az group list
    ```
2. Run the following command to create a new Azure Virtual Machine named `devops-vm` using the Azure CLI:
    ```bash
    az vm create \
        --resource-group kml_rg_main-3d6e5f40d9234d27 \
        --name devops-vm \
        --image Ubuntu2204 \
        --size Standard_B2s \
        --admin-username azureuser \
        --generate-ssh-keys \
        --storage-sku Standard_LRS \
        --os-disk-size-gb 30 \
        --output json \
        --verbose
    ```

## Notes
- `az vm create` command is used to create a new virtual machine in Azure.
- The `--resource-group` parameter specifies the resource group where the VM will be created.
- The `--name` parameter specifies the name of the virtual machine.
- The `--image` parameter specifies the image to use for the virtual machine.
- The `--size` parameter specifies the size of the virtual machine.
- The `--admin-username` parameter specifies the username for the virtual machine.
- The `--generate-ssh-keys` parameter generates SSH keys for secure access to the virtual machine.
- The `--storage-sku` parameter specifies the storage account type for the virtual machine.
- The `--os-disk-size-gb` parameter specifies the size of the OS disk for the virtual machine.
- The `--output` parameter specifies the output format for the command.
- The `--verbose` parameter provides detailed information about the command execution.
