## Solution
1. Login to the Azure portal using the provided credentials.
2. Navigate to Virtual Networks and select the `xfusion-priv-vnet`.
3. In the left-hand menu, click on "Peerings" and then click on "+ Add" to create a new peering.
4. Fill in the peering details:
   - Name: `xfusion-pub-to-priv-peering`
   - Select the public VNet (`xfusion-pub-vnet`) as the peering target.
   - Local Name: `xfusion-pub-to-priv-peering`
3. Navigate to the public VM (`xfusion-pub-vm`) and SSH into it using the following command:
```bash
ssh azureuser@<public-vm-ip-address>
```
4. Navigate to the private VM's IP address and test the connection by pinging it:
```bash
ping 10.1.1.4
```
