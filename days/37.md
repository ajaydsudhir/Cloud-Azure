# Day 37: Setting Up MySQL on a Virtual Machine in Azure

## Task
The Nautilus DevOps team is tasked with integrating a PHP application hosted on an Azure VM with a MySQL database hosted on another Azure VM. This will validate the application's ability to connect to the database in the cloud.

1. **Create the MySQL VM:**
    - Create a Mysql server named `nautilus-mysql-vm` using the **Percona Server for MySQL** image (published by **Jetware**) from the Azure Marketplace.
    - Configure the VM in the **Central US** region.
    - Use `Password` as the authentication type.
    - Set the **username** as `nautilus_admin` and the **password** as `Namin@123456`.
    - Size: `Standard B1s`
    - Allow the public inbound port `22` during VM creation. Port `3306` is not selectable in the create wizard, so add it as an inbound rule to the VM's network security group (NSG) **after** the VM is created to enable MySQL access.
    - Under Disks tab choose OS disk type : `standard HDD`

2. **Setup the MySQL Database:**
    - SSH into the `nautilus-mysql-vm`.
    - Use the `sudo /jet/enter mysql` command to access the MySQL shell.
    - Create a database named `nautilus_db`.
    - Create a MySQL user named `nautilus_user` with password `password123`.
    - The user must be created with the `'%'` host (i.e., `'nautilus_user'@'%'`) so it can connect remotely from the PHP VM.
    - Grant all privileges on the `nautilus_db` database to `'nautilus_user'@'%'`.
    - Ensure the privileges are applied by running the appropriate command to flush privileges.

3. **PHP VM Setup:**
    - A VM named `nautilus-php-vm` already exists in the **East US** region.
    - This VM is hosting a PHP application and contains a pre-existing `db_test.php` file in the `/var/www/html/` directory.
    - Passwordless SSH access to this VM is **already configured from the lab host**, so you can simply run `ssh azureuser@<php-vm-public-ip>` to log in (no password required).

4. **Database Connection Configuration:**
    - Retrieve the public IP address of the `nautilus-mysql-vm`.
    - SSH into the `nautilus-php-vm` by running `ssh azureuser@<php-vm-public-ip>` from the lab host, then open the `/var/www/html/db_test.php` file.
    - Update the connection variables to reflect the following:
        ```
        $servername = "<mysql-vm-public-ip>";
        $username = "nautilus_user";
        $password = "password123";
        $dbname = "nautilus_db";
        $port = 3306;
        ```
    - Ensure that the mysqli connection utilizes the port variable as the fifth argument, for example:
    ```
        $conn = new mysqli($servername, $username, $password, $dbname, $port);
    ```
    - Save the file and verify there are no syntax errors before testing the connection in a browser.

5. **Validation:**
    - Access the `db_test.php` file from the `nautilus-php-vm` using its public IP address/db_test.php.
    - Ensure the file displays the message `Connected successfully`, confirming the connection between the PHP application and the MySQL database.

## Solution
1. Login to the Azure portal using the provided credentials.
2. Navigate to "Virtual Machines" and create a new VM with the following specifications:
   - Name: `nautilus-mysql-vm`
   - Region: `Central US`
   - Availability options: `No infrastructure redundancy required`
   - Security type: `Standard`
   - Image: `Percona Server for MySQL` (published by Jetware)
   - Size: `Standard B1s`
   - Authentication type: `Password`
   - Username: `nautilus_admin`
   - Password: `Namin@123456`
   - Allow inbound port `22` for SSH access. 
   - OS disk type: `Standard HDD`
3. After the VM is created, navigate to the "Networking" tab of the `nautilus-mysql-vm` and add an inbound security rule to allow traffic on port `3306` for MySQL access.
4. SSH into the `nautilus-mysql-vm` using the command:
   ```
   ssh nautilus_admin@<mysql-vm-public-ip>
   ```
5. Access the MySQL shell using the following command:
   ```
   sudo /jet/enter mysql
   ```
6. Create the database and user with the following commands:
   ```sql
   CREATE DATABASE nautilus_db;
   CREATE USER 'nautilus_user'@'%' IDENTIFIED BY 'password123';
   GRANT ALL PRIVILEGES ON nautilus_db.* TO 'nautilus_user'@'%';
   FLUSH PRIVILEGES;
   ```
7. Retrieve the public IP address of the `nautilus-mysql-vm` from the Azure portal.
8. SSH into the `nautilus-php-vm` using:
   ```
   ssh azureuser@<nautilus-php-vm-public-ip>
   ```
9. Edit the `db_test.php` file located in `/var/www/html/` and update the connection variables as follows:
   ```php
   $servername = "<mysql-vm-public-ip>";
   $username = "nautilus_user";
   $password = "password123";
   $dbname = "nautilus_db";
   $port = 3306;
   $conn = new mysqli($servername, $username, $password, $dbname, $port);
   ```
10. Save the changes and ensure there are no syntax errors in the PHP file.
11. Open a web browser and navigate to `http://<php-vm-public-ip>/db_test.php` to verify the connection. You should see the message `Connected successfully`, confirming that the PHP application on the `nautilus-php-vm` can successfully connect to the MySQL database on the `nautilus-mysql-vm`.
