## Solution
1. Login to Azure Portal using the provided credentials.
2. Navigate to the "Virtual Networks" service.
3. Click on "Create" to start creating a new Virtual Network.
4. Fill in the required details:
   - Name: `devops-vnet`
   - Address space (IPv4 CIDR): `10.0.0.0/16`
5. Click on "Add a subnet" to create a new subnet within the VNet.
6. Fill in the subnet details:
   - Name: `devops-subnet`
   - Address range (IPv4 CIDR): `10.0.0.0/16`
7. Click "Add" to add the subnet.
8. Review the configuration and click "Create" to deploy the Virtual Network and Subnet.
