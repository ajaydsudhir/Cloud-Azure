## Solution
1. Log in to the Azure portal using the provided credentials.
2. Navigate to the "Virtual Machines" section and select the VM named `datacenter-vm-pip`.
3. In the VM's overview page, click on "Networking" in the left-hand menu.
4. Under the "Network Interface" section, click on the NIC associated with the VM.
5. In the NIC's settings, click on "IP configurations".
6. Select the existing IP configuration (usually named `ipconfig1`) and click on "Associate".
7. In the "Associate Public IP address" section, select the public IP address named `datacenter-pip` from the dropdown list.
8. Click "Save" to apply the changes.
