## Solution
1. Login to the Azure portal using the provided credentials.
2. Navigate to the `nautilus-vm` virtual machine.
3. In the VM settings, locate the `Disks` section.
4. Select the existing OS disk and click on `Size + performance`.
5. Change the size from `32Gi` to `64Gi` and save the changes
6. Next, click on `Add data disk` to create a new disk.
7. In the `Add data disk` section, select `Create disk`.
8. Provide the name `nautilus-disk`, select `Standard HDD` as the disk type, and set the size to `64Gi`.
9. Click `Create` to add the new disk to the VM.
10. Once the disk is created, go back to the Azure Client and SSH into the `nautilus-vm` using the IPv4 credentials.
11. After logging in, use the `lsblk` command to list the available disks and identify the new disk (e.g., `/dev/sdc`).
12. Run the following commands to create a filesystem on the new disk and mount it:
``` bash
sudo parted /dev/sdc --script mklabel gpt mkpart xfspart xfs 0% 100%
sudo mkfs.xfs /dev/sdc1
sudo partprobe /dev/sdc1
sudo mkdir -p /mnt/nautilus-disk
sudo mount /dev/sdc1 /mnt/nautilus-disk
```
13. Verify that the new disk is mounted correctly by running `df -h` and checking for `/mnt/nautilus-disk`.
