# Day 19: Convert Public Azure Blob Container to Private

## Task
The Nautilus DevOps team has been using Azure Blob Storage to manage their data. Recently, they realized that one of their containers, currently public, needs to be restricted for internal use only. Your task is to convert a public Azure Blob container to private.

Two blob containers named `nautilus-container-5469` and `nautilus-priv-1873` are available in the `southcentralus` region within the storage account `nautilusst2885`. The `nautilus-container-5469` is currently public, and `nautilus-priv-1873` is private.

1) Convert the blob container `nautilus-container-5469` from public to private while leaving `nautilus-priv-1873` unchanged.

2) Make sure the access level for `nautilus-container-5469` is set to `private` with no public access.

## Solution
1. Log in to the Azure portal using the provided credentials.
2. Navigate to the storage account `nautilusst2885` in the `southcentralus` region.
3. Click on `Blob service` and then select `Containers`.
4. Locate the container `nautilus-container-5469` and click on it.
5. Click on the `Change access level` button and select `Private (no anonymous access)`.
6. Click `OK` to save the changes. 

## Notes
- Configuring the access level of a blob container to private ensures that the data is not publicly accessible and can only be accessed by authorized users or applications.
