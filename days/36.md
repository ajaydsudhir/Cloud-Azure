## Solution
1. Login to the Azure portal using the provided credentials.
2. Navigate to "Storage Accounts" and create a new storage account named `datacenterstor195175333` in the `East US` region with **Locally-redundant storage (LRS)**.
3. After the storage account is created, go to the "Containers" section under "Data Storage" and create a new container named `datacenter-container195175333`.
4. Upload the file `tempfile.txt` from the `/root` directory of the client host to the newly created container using the following command in Azure CLI:
```bash
az storage blob upload --account-name datacenterstor195175333 --container-name datacenter-container195175333 --name tempfile.txt --file /root/tempfile.txt
``` 
5. Navigate to the "Lifecycle Management" section under the storage account settings.
6. Create a new rule with the following configuration:
   - **Rule Name:** `datacenter-del-rule`
   - **Action:** Delete blobs after 7 days of last modification.

## Notes
- `Storage Account` is a fundamental resource in Azure that provides a unique namespace for your data which allows you to store and access data objects like blobs, files, queues, and tables. 
- `Blob Container` is a logical grouping of blobs within a storage account, allowing for organization and management of blob data.
- `Blob Lifecycle Management` is a feature that allows you to automate the management of your blob data by defining rules to transition blobs to cooler storage tiers or delete them after a specified period.
