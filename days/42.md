## Solution
1. Login to the Azure portal using the provided credentials.
2. Navigate to the storage account `devopsst200027048` in the `southcentralus` region and locate the blob container `devops-blob-200027048`.
3. Run the following command on the `azure-client` host to copy the contents of the blob container to the `/opt` directory:
   ```bash
   az storage blob download-batch -d /opt --account-name devopsst200027048 --source devops-blob-200027048
   ```
4. After successfully copying the contents, delete the blob container in the Azure portal by selecting the container and choosing the delete option.
