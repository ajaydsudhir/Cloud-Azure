## Solution
1. Login to the Azure portal using the provided credentials.
2. Navigate to "Container Registries" and create a new registry with the following details:
   - Name: `devopsacr137230256`
   - Location: `East US`
   - Pricing Plan: `Basic`
3. Once the registry is created, enter the `azure-client` host and build the Docker image using the Dockerfile located at `/root/pyapp`:
   ```bash
   az acr login --name devopsacr137230256
   docker build -t devopsacr137230256.azurecr.io/devopsacr137230256:latest . 
   ```
4. Push the Docker image to the ACR repository:
   ```bash
   docker push devopsacr137230256.azurecr.io/devopsacr137230256:latest
   ```
