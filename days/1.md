## Notes
- An `SSH key` is a cryptographic key used for secure access to remote servers where it consists of a public key and a private key. 
- The public key is stored on the server, while the private key remains with the user, during the connection process the private key is used to authenticate the user without needing a password.
- The `RSA` key type is a widely used algorithm for generating SSH keys, known for its security and compatibility with various systems.
