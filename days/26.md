This VNet will host various resources that need to be accessible over the internet. As part of this setup, you need to ensure the VNet has public subnets with automatic public IP assignment for resources. ## Solution
1. Login to the Azure portal using the provided credentials.
2. Navigate to "Virtual Networks" and click on "Create" to create a new VNet.
3. Fill in the required details:
    - Name: `devops-pub-vnet`
    - Region: `East US`
4. Add a subnet:
    - Name: `devops-pub-subnet`
    - Private Subnet: `Off` 
5. Create the VNet and wait for the deployment to complete.
6. Navigate to "Virtual Machines" and click on "Create" to create a new VM.
7. Fill in the required details for the VM:
    - Name: `devops-pub-vm`
    - Region: `East US`
    - Image: Choose a suitable image (e.g., Ubuntu Server)
    - Size: Select an appropriate size
    - Authentication type: SSH public key (Use generated SSH key pair from Azure CLI)
8. Under "Networking", select the previously created VNet `devops-pub-vnet` and the subnet `devops-pub-subnet`.
9. Ensure Public inbound ports are open for SSH (22).
10. Review and create the VM, then wait for the deployment to complete.
11. Once the VM is deployed, verify that you can SSH into the VM using the public IP address assigned to it.
