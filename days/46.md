# Day 46: EventHub to Blob Storage Integration Setup

## Task
The Nautilus DevOps team wants to integrate an Azure Virtual Machine with Azure Event Hubs and Azure Blob Storage for centralized log collection and backup. Follow these steps to complete the task:

1. **Create Azure Event Hubs Namespace:**
    - Create an Event Hubs namespace named `devops-namespace` in the East US region.
    - Select the Standard pricing tier. Make sure to enable `Enable Auto-inflate`.

2. **Create an Event Hub:**
    - Within the namespace, create an Event Hub named `devops-hub`.

3. **Set Up Azure Blob Storage for Log Backup:**
    - Create a Storage Account named `devopsst53596426` in the `East US` region.
    - Create a container named `devops-backup-53596426` within the Storage Account.
    - Ensure the container is publicly accessible for read operations.

4. **Verify the Virtual Machine Configuration:**
    - The **client host** already has a Python script named `send_logs.py` located under `/root`. This script is used to send logs to the Event Hub.
    - **Create a Virtual Machine** named `devops-vm` in the `East US` region.
    - Copy the `send_logs.py` script from the client host to the `/home/azureuser` directory of the `devops-vm`.
    - Modify the script on the VM to also back up the logs to the `devops-backup-53596426` container in the Azure Blob Storage account.

5. **Verify Logs:**
    - Ensure the logs are successfully sent to the Event Hub by checking the Event Hubs metrics in the Azure portal.
    - Verify that the logs are backed up to the `devops-backup-53596426` container in the Azure Blob Storage.

**Notes:**

- Use the existing client host to copy the script to the VM.

## Solution
1. Log in to the Azure portal using the provided credentials.
2. Create an Event Hubs namespace named `devops-namespace` in the `East US` region with the `Standard` pricing tier and `Enable Auto-inflate`.
3. Within the namespace, create a new Event Hub named `devops-hub`.
4. Create a Storage Account with the following details:
   - Name: `devopsst53596426`
   - Region: `East US`
   - Primary Service: Azure Blob Storage or Azure Data Lake Storage
   - Performance: Standard
   - Redundancy: LRS
5. Create a container named `devops-backup-53596426` within the Storage Account and set its access level to `Blob (anonymous read access for blobs only)`.
6. Create a virtual machine with the following details:
    - Name: `devops-vm`
    - Region: `East US`
    - Availability Options: No infrastructure redundancy required
    - Image: Ubuntu Server 24.04 LTS
    - Size: Standard B1s
    - Authentication Type: SSH (Use existing public key)
    - OS Disk Type: Standard SSD
7. Copy the `send_logs.py` script from the client host to the `/home/azureuser` directory of the `devops-vm` by running `scp send_logs.py azureuser@<devops-vm-ip>:/home/azureuser/` on the client host. 
8. Navigate to the `devops-namespace` in the Azure portal, and retrieve the connection string for the Event Hub.
9. Navigate to the `devopsst53596426` Storage Account, and retrieve the connection string for the Blob Storage.
10. SSH into the `devops-vm` and modify the `send_logs.py` script to include the connection strings for both the Event Hub and the Blob Storage, ensuring that logs are sent to the Event Hub and backed up to the Blob Storage container.
11. Run the following commands on the VM to set up the Python environment and install the required packages:
    ```bash
    sudo apt update -y
    sudo apt install python3-venv -y
    python3 -m venv ~/env
    source ~/env/bin/activate
    pip install azure-storage-blob azure-eventhub 
    ```
12. Run `python3 send_logs.py` on the VM to send logs to the Event Hub and back them up to the Blob Storage.
