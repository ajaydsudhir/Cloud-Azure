## Task
The Nautilus DevOps team is migrating a portion of its infrastructure to Azure. During the migration, they have created several virtual machines (VMs) in different regions. The team identified one VM that is experiencing increased workload demands and requires additional compute resources to maintain optimal performance.

2) Ensure the VM is in the `running` state after the size change is complete.

## Solution
1. Log in to the Azure portal using the provided credentials.
2. Navigate to the "Virtual Machines" section in the Azure portal.
3. Locate and select the virtual machine named `devops-vm` from the list of available VMs.
4. In the "Availability + Size" section, click on the "Size" option to view the available VM sizes.
5. From the list of available sizes, select `Standard_B2s` to change the VM size.
6. Click on the "Resize" button to apply the size change.
