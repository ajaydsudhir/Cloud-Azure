## Solution
1. Log in to the Azure portal using the provided credentials.
2. Navigate to the "Virtual Machines" section and select the VM named `xfusion-vm`.
3. In the VM's settings, go to the "Networking" tab.
4. Click on "Attach network interface" and select the existing NIC named `xfusion-nic`.
5. Confirm the attachment and wait for the process to complete.
6. Verify that the NIC's status is now `attached` in the VM's networking settings.
