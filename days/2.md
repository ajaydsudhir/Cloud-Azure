## Solution
1. Log in to the Azure portal using the provided credentials.
2. Navigate to the "Virtual Machines" section and click on "Create" to start the process of creating a new virtual machine.
3. Select the existing resource group for the VM.
4. Enter the VM name as `nautilus-vm` and select the `West US` region.
5. Choose the `Ubuntu 24.04 LTS` image from the list of available images.
6. Select the VM size as `Standard_B1s`.
7. Configure the networking settings to attach a default Network Security Group (NSG) that allows inbound SSH (port 22).
8. Attach a 30 GB storage disk of type `Standard HDD` to the VM.
9. Review the configuration settings and click on "Create" to deploy the virtual machine.
10. Once the VM is created, obtain its public IP address from the Azure portal.
11. Use the public IP address to SSH into the virtual machine.

## Notes
- `Virtual Machine` is a compute resource that allows you to run applications and services in the cloud. It provides the flexibility to choose the operating system, size, and configuration based on your requirements.
- `Network Security Group (NSG)` is a security feature that allows you to control inbound and outbound traffic to your virtual machine. By default, it blocks all inbound traffic except for the ports you explicitly allow, such as SSH (port 22) for remote access.
