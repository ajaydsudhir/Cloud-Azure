## Solution
1. Log in to the Azure portal using the provided credentials.
2. Navigate to the "Network Security Groups" section.
3. Click on "Create" to create a new NSG.
4. Fill in the required details:
    - Name: `devops-nsg`
    - Resource Group: Select an existing resource group or create a new one.
5. Click "Review + create" and then "Create" to deploy the NSG.
6. Once the NSG is created, navigate to the "Inbound security rules" section.
7. Click on "Add" to create a new inbound security rule.
8. For the first rule, fill in the following details:
    - Name: `Allow-HTTP`
    - Priority: `100`
    - Source: `Any`
    - Source port ranges: `*`
    - Destination: `Any`
    - Destination port ranges: `80`
    - Protocol: `TCP`
    - Action: `Allow`
9. Click "Add" to save the rule.
10. Repeat steps 7-9 to create the second inbound security rule with the following details:
    - Name: `Allow-SSH`
    - Priority: `200`
    - Source: `Any`
    - Source port ranges: `*`
    - Destination: `Any`
    - Destination port ranges: `22`
    - Protocol: `TCP`
    - Action: `Allow`

## Notes
- `Network Security Groups (NSGs)` are used to control inbound and outbound traffic to Azure resources. 
- They act as a virtual firewall, allowing you to define rules that permit or deny traffic based on source and destination IP addresses, ports, and protocols.
