## Solution
1. Log in to the Azure portal using the provided credentials.
2. Navigate to the "SQL databases" section and click on "Create SQL database".
3. Fill in the required details:
   - Database name: `devops-sqldb`
   - Server: Create a new server with the name `devops-server-942876045` in the `southcentralus` region and use `devops-admin` as the admin username.
   - Compute + storage: Select **Basic**
   - Backup storage redundancy: Choose **Locally-redundant backup storage*
   - Set the database size to **2 GiB**.
4. Keep all other settings as default and click "Review + create".
5. After reviewing the settings, click "Create" to deploy the database.
