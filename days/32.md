# Day 32: Synchronizing Containers Using the CLI

## Task
As part of a data migration project, the team lead has tasked the team with migrating data from an existing Azure Blob container to a new Blob container. The existing container contains a substantial amount of data that must be accurately transferred to the new container. The team is responsible for creating the new Blob container and ensuring that all data from the existing container is copied or synced to the new container completely and accurately. It is imperative to perform thorough verification steps to confirm that all data has been successfully transferred to the new container without any loss or corruption.

As a member of the Nautilus DevOps Team, your task is to perform the following:

**Create a New Private Azure Blob Container:** Name the container `devops-dest-613895420` under the storage account `devopsst613895420`.

**Data Migration:** Migrate the file `devops.txt` from the existing `devops-source-613895420` container to the new `devops-dest-613895420` container.

**Ensure Data Consistency:** Ensure that both containers have the file `devops.txt` and confirm the file content is identical in both containers.

**Use Azure CLI:** Use the Azure CLI to perform the creation and data migration tasks.

## Solution
1. Create the new private Azure Blob container `devops-dest-613895420` under the storage account `devopsst613895420` using the Azure CLI:
```bash
az storage container create --name devops-dest-613895420 --account-name devopsst613895420
```
2. Run the following commads to list the containers and blobs to verify the creation of the new container and the presence of the file in the source container:
```bash
az storage container list --account-name devopsst613895420 --output table
az storage blob list --account-name devopsst613895420 --container-name devops-source-613895420 --output table
```
3. Use the following command to copy the file `devops.txt` from the source container `devops-source-613895420` to the destination container `devops-dest-613895420`:
```bash
az storage blob copy start --account-name devopsst613895420 --destination-container devops-dest-613895420 --destination-blob devops.txt --source-container devops-source-613895420 --source-blob devops.txt
```
4. Verify that the file `devops.txt` has been successfully copied to the destination container:
```bash
az storage blob list --account-name devopsst613895420 --container-name devops-dest-613895420 --output table
```

## Notes
- `az storage container create` command is used to create a new container in the specified storage account.
- `az storage blob copy start` command is used to initiate the copy operation of a blob from one container to another within the same storage account.
- `az storage blob list` command is used to list the blobs in a specified container, allowing verification of the presence of the copied file.
