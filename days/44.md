## Task

    - Select the **Standard** pricing tier. Make sure to enable `Enable Auto-inflate`.

2. **Create an Event Hub:**

4. **Verify Logs:**
    - Ensure the logs are successfully sent to the Event Hub by checking the Event Hubs metrics in the Azure portal.

**Notes:**

  - Use the existing VM `nautilus-vm` to send logs.

## Solution
1. Log in to the Azure portal using the provided credentials.
2. Navigate to **Event Hubs**.
3. Create a new Event Hubs namespace named `nautilus-namespace` in the **East US** region with the **Standard** pricing tier and **Enable Auto-inflate**.
4. Under the newly created namespace, create an Event Hub named `nautilus-hub`.
5. SSH into the existing VM `nautilus-vm` using the public IP address.
6. Under `nautilus-namespace` in the Azure portal, navigate to **Shared access policies** and copy the **Primary connection string** for the `RootManageSharedAccessKey` policy.
7. Update `send_logs.py` to include the copied connection string for the Event Hub.
8. Run `python3 send_logs.py` multiple times to send logs to the Event Hub.
