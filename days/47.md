Recognizing the scale of this undertaking, they have opted to approach the migration in incremental steps rather than as a single massive transition. As part of this migration, they are focusing on setting up and managing Azure SQL Databases, implementing backup processes, and ensuring data recovery. **Task 2: Create a Storage Account**

1. Create a **Storage Account** named `devopsst953196606`.

2. Configure a **Blob Container** named `devops-container-953196606` within this storage account.

**Task 3: Backup the Azure SQL Database**

1. Take a backup of the Azure SQL Database instance `devops-sqldb` and store it in the **Blob Container**:

    - **Blob Container:** `devops-container-953196606`.

**Task 4: Download the Backup**

1. Download the backup file from the Blob Container to the `/opt` directory on the `azure-client` host.

2. Ensure the file is accessible and properly named based on its extension.

## Solution
1. Log in to the Azure portal using the provided credentials.
2. Create a new SQL server with the following details:
    - Server Name: `devops-server-953196606`
    - Location: `West US`
    - Admin Username: `devops-admin`
    - Admin Password: Set an appropriate password.
    - Allow Azure services and resources to access this server: `Yes`
3. After the server is created, create a new SQL Database with the following configurations:
    - Database Name: `devops-sqldb`
    - Server: `devops-server-953196606` 
    - Service Tier: `Basic`
    - Database Size: `2 GiB`
    - Backup Storage Redundancy: `Locally-redundant backup storage.`
4. Create a new Storage Account with the following details:
    - Storage Account Name: `devopsst953196606`
    - Location: `West US`
    - Preffered Storage Type: `Azure Blob Storage or Azure Data Lake Storage`
    - Performance: `Standard`
    - Replication: `Locally-redundant storage (LRS)`
5. Within the Storage Account, create a new Blob Container named `devops-container-953196606`.
6. To back up the SQL Database, navigate to the SQL Database `devops-sqldb`, select `Export`, and configure the export settings:
    - Backup File Name: `devops-db-backup`
    - Storage Account: `devopsst953196606`
    - Blob Container: `devops-container-953196606`
    - Server Admin Login: `devops-admin`
    - Server Admin Password: Enter the password set for the SQL server.
7. Run the following commands on the `azure-client` host to download the backup file from the Blob Container to the `/opt` directory:
    ```bash
    sudo az storage blob download --account-name devopsst953196606 --container-name devops-container-953196606 --name devops-db-backup.bacpac --file /opt/devops-db-backup.bacpac
    cd /opt
    sudo chmod 644 devops-db-backup.bacpac
    ls -l 
    sudo chmod 755 /opt/devops-db-backup.bacpac
    ```
