## Solution
1. Log in to the Azure portal using the provided credentials.
2. Navigate to the storage account `nautilusst4468` in the `centralus` region.
3. Access the Blob container named `nautilus-blob-17110`.
4. Write the following command to copy the file `/tmp/nautilus.txt` to the Blob container `nautilus-blob-17110`:
```bash
az storage blob upload --account-name nautilusst4468 --container-name nautilus-blob-17110 --name nautilus.txt --file /tmp/nautilus.txt
```
5. Refresh the Blob container view to confirm that the file `nautilus.txt` has been successfully uploaded.

## Notes
